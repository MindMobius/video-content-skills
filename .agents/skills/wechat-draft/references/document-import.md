# 微信文档导入交付

当经过验证的公众号文章包含正文图片，或者富文本粘贴曾出现图片丢失、乱序、异步上传不确定时读取本页。

## 它解决什么

`article-import.docx` 是从**同一份最终 Content**派生的瞬时平台交接文件。正文文字和图片先在本地形成一个可检查的整体，再交给微信官方文档导入器完成转换和图片托管。它减少逐张插图、本地路径、Base64、剪贴板状态和异步上传顺序造成的不确定性。

DOCX 不是第七种业务产物，不是新的正文来源，也不是草稿完成证据。事实和结构仍以当前 Content 为准；微信平台状态仍以刷新回读和 Draft Receipt 为准。

## 何时优先使用

- 正文有一张或多张来源图片，尤其是需要在论述转场处穿插多张视频帧；
- 当前 Job 的 handoff package 已有经过检查的 `article-import.docx`；
- 当前可见微信编辑器提供文档导入入口。

无图短文或文档导入入口不可用时，可以使用瞬时富文本剪贴板。两条路径只是在同一 Content 上选择交付载体，不能产生两份不同稿件，也不能在状态不确定的同一编辑器里叠加使用。

## 上传前合同

1. `wechat_prepare` 已通过，`draft_target` 明确是 `create_new` 或精确的原 `appmsgid`。
2. `content_validate.valid=true`，DOCX 必须来自这一 Content 的最终文本，而不是旧预览或旧 Content。
3. 文件只放在当前 Job 的 `work/<content_id>/handoff-package/`；不得放到状态根顶层，也不得提交 Git。
4. 正文 image block 按 Content 顺序各嵌入一次；每张图都来自包内已验证的 `video_cover` 或最终 `video_frame` 资产，不能使用 scout/contact sheet 或低清预览。平台封面仍单独设置；如果 Content 本身把封面作为正文 image block，它仍属于正文，不能因为另选平台封面而跳过。
5. 每张内嵌图的像素宽高比必须与 DOCX 中 `wp:extent` 的显示宽高比一致。可以只限制最大宽度并让高度自动缩放，不能同时写死宽和高，也不能统一裁成 16:9。竖屏来源必须仍是竖屏，横屏和方形同理。
6. 上传前打开或解析 DOCX，核对正文开头、中部、结尾，图片数量与顺序、图片清晰度与画幅，以及没有缺图、空白图片或本机路径文字。
7. 标题、摘要、平台封面、作者、原创状态和“内容由AI生成”不假定由 DOCX 正确带入，仍按编辑器合同分别设置；文件名产生的 `article-import` 不能作为最终标题。

## 导入与验收

1. 在当前已确认的可见编辑器中，预先监听文件选择，再点击真正的文档导入控件并选择唯一的 DOCX。
2. 等待微信完成文档转换。导入进度、成功提示或正文出现一部分都不是完成证据。
3. 检查实际正文开头、中部和结尾；比较 Content 的预期图片数量、顺序和对应段落。
4. 所有真实图片必须可见、加载完成、尺寸非零并已由微信托管；排除 ProseMirror 等编辑器产生的零尺寸分隔图片。比较每张图的 `naturalWidth/naturalHeight` 与页面显示 `width/height`，宽高比不一致就停止，不能把固定容器中的拉伸图当成成功。
5. 再填写准确标题和摘要，主动选择原视频封面而不是相信默认候选，保持作者空白和原创未选，并按 Profile 选择“内容由AI生成”。
6. 只保存草稿，然后刷新或重新打开同一数字 `appmsgid`，重新回读正文、图片、封面、摘要和创作来源，最后才绑定 Draft Receipt。

## 浏览器与文件选择能力

- 选择当前已登录、且 Agent 实际能控制文件选择器的浏览器目标；不固定某一种浏览器或旧标签页。
- `setFiles: Not allowed` 表示当前控制面不允许附件注入，复制或改名 DOCX 不会改变这个能力。先保持同一登录会话，换到可控的新标签页或真实文件选择器；若没有可控入口，才停在登录/人工边界。
- 旧标签页输入或 evaluate 超时后，先重读同一目标；只有确认标签页已失效，才在同一已登录会话中新开 Agent 控制标签页。
- 任意一次上传状态不确定时，不得再次上传同一文件、换一份副本或叠加剪贴板。

## 超时与回退

- 文件选择、上传或转换超时后，先检查同一编辑器、导入弹窗和正文是否已经变化；不要立即再次上传，也不要新建第二篇。
- 如果正文已经完整出现，继续做图片和文本验收，不再导入。
- 如果状态无法判断，保持 Job 未完成并按恢复清单读取同一目标；不得用剪贴板覆盖一个可能仍在转换的 DOCX。
- 只有确认文档导入没有产生正文，而且当前目标仍是同一空白编辑器时，才允许重试同一文件或改用剪贴板后备路径。
